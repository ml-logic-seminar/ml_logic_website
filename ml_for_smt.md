# ⚙️ Machine Learning for SMT

This page highlights ongoing and past research efforts applying machine learning to improve Satisfiability Modulo Theories (SMT) solvers at the **<a href="https://vganesh1.github.io/group.html" target="_blank">reasoning and learning research group @ Georgia Tech led by Professor Vijay Ganesh</a>**.
